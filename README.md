# OMIX STUDIOS

Independent software and game studio building practical Windows/Android products and original games.

## Products

### PC Smart Utility
Windows system utility for cleanup, diagnostics, system tools and everyday PC maintenance.

[Open in Microsoft Store](https://apps.microsoft.com/detail/9NW5DMR2XQ36)

### PC Smart Utility Pro
Premium Windows utility with additional tools for users who want more control.

[Find on Microsoft Store](https://apps.microsoft.com/search?query=PC%20Smart%20Utility%20Pro)

### IPO Master Guide
Android app focused on IPO education and tracking for Indian retail users.

[Open on Google Play](https://play.google.com/store/apps/details?id=ipo.master)

## Games

### GTEEAA CITY 6
Original 3D open-world action game for Windows with story missions, driving, combat, boats, helicopters and an original city.

[View on Microsoft Store](https://apps.microsoft.com/detail/9N13CM8F1XP1)

### Tiger House
Original tiger-and-goat strategy board game concept.
